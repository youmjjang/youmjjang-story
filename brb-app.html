BR-B · T10 논문 반영 애플리케이션

HTTP Status Pattern Analyzer

웹 서버 로그에서 HTTP 상태코드 유형별 시간 구간 및 경고 임계값 설정에 따른 이상 패턴 탐지 성능 비교

웹 로그 분석이 익숙하지 않은 사용자가 대량 로그에서 먼저 확인할 Host/IP와 그 이유를 빠르게 찾을 수 있도록 돕습니다.

논문의 모의실험에서 유형별 F1이 가장 높았던 기준을 기본 분석 규칙으로 사용합니다. 공격을 확정하는 도구가 아니라 로그 검토 우선순위를 좁혀주는 보조 도구입니다.

분석 결과

논문 기반 기준

해석

반복 횟수가 기준을 넘은 Host/IP부터 우선 확인하도록 보여줍니다. 401/403은 인증·권한, 404는 경로 탐색, 429는 과도한 요청, 5xx는 서버 오류의 집중 발생을 의미합니다.

✓

짧은 검증 방법

검증 위치: 포트폴리오의 프로젝트 영역에서 HTTP Status Pattern Analyzer → 앱 실행하기로 들어옵니다.

  1. 예시 로그 불러오기를 누릅니다.
  2. 논문 기준으로 분석하기를 누릅니다.
  3. 분석 결과에서 우선 확인 Host/IP · 상태코드 유형 · 적용 시간 구간/반복 횟수 · 주요 경로 · 확인 이유가 표시되는지 확인합니다.

통과 기준: 예시 로그의 401/403, 404, 429, 5xx 반복 패턴이 유형별 기준에 따라 우선 확인 항목으로 표시되고, 각 항목에 Host/IP와 적용 기준 및 이유가 함께 나오면 통과입니다. 잘못된 형식의 로그를 넣었을 때 오류 안내만 표시되고 페이지가 멈추지 않으면 예외 처리도 정상입니다.
