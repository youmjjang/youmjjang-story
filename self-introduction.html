자기소개서

먼저 시작하고, 결과를 보고 다시 고칩니다

저는 모든 준비가 끝날 때까지 기다리기보다 먼저 실행해 보고, 실제 결과에서 부족한 부분을 찾으면 다시 고치는 편인 김유미입니다.

이 방식이 자리 잡은 계기는 2023년 일본 교환학생 경험이었습니다. 익숙하지 않은 언어와 수업 방식 속에서 생활하다 보니 모든 것을 충분히 준비한 뒤 시작하는 것은 불가능했습니다. 모르는 일이 생길 때마다 직접 해 보고, 틀리면 다시 고치는 수밖에 없었습니다. 그때부터 완벽하게 준비하는 것보다 시작한 뒤 수정하는 방식이 저에게 더 잘 맞는다는 것을 알게 됐습니다.

2026년 교육 과정에서도 같은 방식이 반복됐습니다. 8월 26일에는 잘한 점을 들은 날에도 저녁 기록에 스스로 못한 점을 남겼고, 9월 8일에는 경청이 부족했다고 적은 뒤 다음 행동을 수정했습니다. 반대로 9월 3일에는 ‘우선 시도하고 보겠습니다’를 첫 행동으로 정했고, 9월 18일에는 맡은 일을 마친 뒤 남는 시간에 프로젝트를 이어 갔습니다.

개인 프로젝트 Mini SOC는 단순 로그 출력에서 시작해 HTTP 오류와 반복 접근 탐지, JSON 경보, 알림 서버, 일일 리포트까지 확장했습니다. 팀 프로젝트 GIGANG에서는 서버 화면에 위험도를 표시하는 데서 그치지 않고 사용자 PC의 웹 접근과 파일 선택 이벤트를 수집해 정책 흐름과 연결하는 방향으로 확장했습니다.

저는 처음부터 모든 답을 알고 시작하지 않습니다. 대신 실행 결과를 확인하고 안 된 이유를 기록하며 다음 행동을 더 구체적으로 바꿉니다. 앞으로도 보안 관제와 로그 분석 업무에서 이상 징후의 원인을 찾고 반복되는 대응을 자동화해 실제 현장에서 확인 가능한 결과를 만드는 사람이 되고 싶습니다.
