# 김유미 Career Story · BRA 제출용

공개 사이트: https://youmjjang.github.io/youmjjang-story/

## 구성
- `index.html` : Career Story 메인 사이트
- `resume.html` : 이력서
- `self-introduction.html` : 자기소개서
- `career.html` : 경력기술서
- `update.html` : 새 기록을 넣어 결과를 다시 만드는 확인용 페이지
- `update.js` : 입력값을 바탕으로 수치와 문단 후보를 만드는 갱신 로직
- `BRA_CHECKLIST.md` : 조건 대응표

## 새 폴더에서 실행
1. 저장소 ZIP을 다운로드한다.
2. 새 폴더에 압축을 푼다.
3. 그 폴더에서 `python -m http.server 8000`을 실행한다.
4. 브라우저에서 `http://localhost:8000`을 연다.
5. 이력서·자기소개서·경력기술서와 `update.html`을 확인한다.

정적 HTML/CSS/JavaScript 사이트이므로 별도 빌드나 패키지 설치가 필요하지 않습니다.

## 새 기록 갱신 장치 확인
공개 포트폴리오 화면과 과제 확인 기능을 분리하기 위해 갱신 장치는 별도 페이지에 두었습니다.

- 온라인: https://youmjjang.github.io/youmjjang-story/update.html
- 로컬: `http://localhost:8000/update.html`

같은 JSON을 두 번 넣고 `다시 계산`을 누르면 같은 수치와 같은 문단 후보가 나옵니다. `update.js`는 날짜순 정렬만 사용하고 난수, 현재 시각, 외부 API를 사용하지 않습니다.

## T10 / T13
- T10 연구 결과는 메인 사이트 대표작에 수록했습니다.
- T13은 아직 결과물이 완성되지 않아 메인 사이트에 `다음 앱 프로젝트` 자리만 두었고, 완료 후 앱 이름·핵심 화면·실행 링크로 교체합니다.

## 안전·개인정보
API 키, 비밀번호, 토큰, 동료 실명은 공개 저장소에 넣지 않습니다. 테스트·모의 데이터는 실제 운영 결과처럼 표현하지 않습니다.

## AI와 사용자 역할
- AI에게 맡긴 일: 교육 과정 기록에서 표현을 묶고 날짜 장면 후보를 정리하며 문장과 코드 초안을 보조
- 직접 판단한 일: 어떤 장면을 남길지, 사실과 과장을 구분하는 기준, 프로젝트 범위와 한계, 세 능력과 경험의 연결
- 사용하지 않은 AI 제안: 근거보다 과장된 리더십, ‘항상 잘했다’ 같은 표현, 근거가 약한 일반적 강점
