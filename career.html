BRA-C07~C08 · CAREER DESCRIPTION

경력기술서

각 경험을 자기조절력·대인관계력·자기동기력 가운데 하나와 연결하고 상황·행동·결과로 정리했습니다.

GIGANG · 자기동기력

상황초기 구조는 외부 AI/SaaS 이벤트의 위험도를 관리자 화면에 보여주는 데 집중돼 있어 실제 사용자 행동 통제와의 연결이 약했습니다.행동사용자 PC의 웹 접근·파일 선택 이벤트를 수집하고 Windows Agent에서 사용자·PC 정보를 보강해 중앙 정책 흐름과 연결했습니다. 사용자 역할, SaaS 승인 여부, DB 접근 로그를 함께 보는 방향으로 구조를 확장했습니다.결과모니터링 결과를 표시하는 수준에서 실제 사용자 환경의 경고·차단까지 이어지는 흐름을 테스트할 수 있게 됐습니다.

Mini SOC · 자기동기력

상황보안 관제에 관심이 있었지만 로그 수집부터 탐지·알림까지 직접 연결한 경험이 부족했습니다.행동개인 프로젝트로 시작해 Docker/Nginx 환경, Python 로그 파서, 오류·반복 접근 탐지, JSON 경보, Flask 알림 서버, 일일 리포트를 단계적으로 추가했습니다.결과웹 로그가 발생한 뒤 탐지·기록·알림·보고서로 이어지는 작은 관제 흐름을 직접 구현했습니다.

카페 근무 · 대인관계력

상황처음에는 업무에 적응하기 어려웠고 동료와 함께 바쁜 매장을 운영해야 했습니다.행동업무 순서를 익히고 동료와 필요한 일을 나눠 수행했습니다. 새 직원에게 업무를 설명하고 동료 의견을 듣고 전달하는 역할도 맡았습니다.결과장기간 근무를 이어 갔고 업무 수행을 인정받아 점장 제안을 받았습니다. 함께 일한 동료에게 편지를 받은 경험도 남았습니다.

일본 교환학생 · 자기조절력

상황2023년 약 반년 동안 익숙하지 않은 언어·수업 방식·생활 환경에 적응해야 했습니다.행동준비가 완벽해질 때까지 기다리기보다 모르는 일을 직접 시도하고, 막히면 다시 찾아 수정하는 방식으로 학업과 생활을 이어 갔습니다.결과교환학생 과정을 마쳤고 Excel Programming 수업에서 VBA 프로그램을 완성했습니다. 이후 새로운 과제에서도 먼저 시작하고 수정하는 방식이 습관으로 남았습니다.

R&D 인턴 · 자기조절력

상황입사 초기부터 SW 요구사항 정의서, 시스템 SW 정의서, SOW와 Specification 등 익숙하지 않은 문서를 빠르게 확인해야 했습니다.행동문서 요구사항과 실제 시스템 동작을 비교하고 POC 과정에서 발생한 기능·오류 현상을 정리했습니다.결과구현 결과뿐 아니라 요구사항과 실제 동작의 차이를 확인하고 문서화하는 방식의 중요성을 경험했습니다.
